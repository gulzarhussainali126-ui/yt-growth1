# YT Growth — Face 1 Landing Page

Next.js 14 App Router, TypeScript, Tailwind CSS, Framer Motion, Radix (shadcn-compatible primitives), Lucide and Lenis.

## Start

```bash
npm install
npm run dev
```

Open http://localhost:3000. Set `NEXT_PUBLIC_SITE_URL=https://your-domain.com` before production build for canonical/structured data.

## Scope

Landing page only. Charts, counters, insights, prices, and provider names are **illustrative**, not live data or partnerships. No OAuth, billing, or backend is included. The early-access CTA opens a placeholder email; replace it with a real address before deployment. Privacy/Terms and Blog are placeholders, not published pages. SearchAction schema describes a future search experience and should be removed until search is implemented.

## Deploy

Use a Next.js-capable host or server; static Netlify drag-and-drop is not sufficient for a standard Next.js app.
